# MeshCore TCP Proxy

![Supports aarch64](https://img.shields.io/badge/aarch64-yes-blue.svg)
![Supports amd64](https://img.shields.io/badge/amd64-yes-blue.svg)

[![Open this add-on in Home Assistant](https://my.home-assistant.io/badges/supervisor_addon.svg)](https://my.home-assistant.io/redirect/supervisor_addon/?addon=ha-core-splitter&repository_url=https%3A%2F%2Fgithub.com%2FOddiesea%2Foddiesea-ha-addons)

Shares one MeshCore companion radio with every TCP client on the Home Assistant host network. That includes the MeshCore integration, meshcore-cli, and the MeshCore app.

The program is [Core Splitter](https://github.com/ogarcia/coresplitter) by Óscar Amor, GPL-3.0. Setup is on the Documentation tab, a few updates for app version support and other fixes have been applied.
